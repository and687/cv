Andrea AMATO — CV Administration

Présentation technique

Architecture du projet

Un CV responsive développé avec HTML, CSS, Bootstrap et JavaScript.

Schéma

Comment les éléments communiquent

1. Développement

VS Code et l'extension Live Server lancent un serveur local pour prévisualiser le site.

→

2. Interface web

HTML structure le CV, CSS le met en forme, Bootstrap fournit la grille responsive, la navigation et les accordéons d’expériences et de projets, et JavaScript gère l'affichage et l'administration.

→

3. Navigateur

Le navigateur affiche le CV et son panneau d'administration, sur ordinateur comme sur mobile.

→

4. Supabase

Le SDK JavaScript charge les projets, les expériences et les compétences avec la clé publique. Le formulaire de contact insère les messages sans pouvoir les lire.

Organisation

Fichiers du projet

index.html

Contient la structure du CV et les champs du panneau d'administration.

style.css

Contient le thème visuel et les règles de mise en page personnalisées.

app.js

Récupère les contenus Supabase de façon asynchrone, génère les accordéons Bootstrap et envoie les messages du formulaire.

supabase-config.js

Contient l’URL du projet et la clé publique (anon/publishable). Ne jamais y placer la clé secrète service_role.

supabase-setup.sql

Crée les tables, les règles RLS de lecture publique et les données de départ du portfolio.

architecture.html

Présente le schéma et explique les choix d'architecture du projet.

Configuration et sécurité

Connecter Supabase en sécurité

  1. Dans Supabase, ouvrez le SQL Editor et exécutez supabase-setup.sql pour créer les tables et insérer les données de départ.
  2. Dans supabase-config.js, renseignez l’URL du projet et sa clé publique (clé anon ou publishable).
  3. Servez le dossier avec Live Server ou un hébergement web : les appels réseau ne fonctionnent pas depuis une page ouverte directement en file://.

Clé publique : elle est destinée au navigateur et ne donne que les droits autorisés par les politiques RLS. Les tables projects, experiences et skills sont accessibles en lecture publique ; la table messages autorise l’insertion mais pas la lecture publique.

Clé secrète service_role : elle contourne RLS. Ne la mettez jamais dans le JavaScript, le HTML ou le dépôt Git ; elle doit rester sur un serveur sécurisé.

L’administration actuelle du CV conserve encore ses modifications dans le localStorage du navigateur. Seuls les projets, les expériences et les compétences sont chargés depuis Supabase.
